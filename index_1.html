// POR QUE O NET GUARD?

Transformando manutenção em informação.

Em ambientes com muitos computadores, verificar cada equipamento individualmente pode consumir tempo. O projeto propõe uma abordagem centralizada para facilitar essa identificação.

⌁

Detecção

Identificação dos computadores disponíveis na rede local para facilitar a visualização do ambiente.

◈

Autorização

As informações de hardware podem ser disponibilizadas pelo computador aluno mediante autorização.

⚙

Diagnóstico

Os dados coletados podem auxiliar na identificação de possíveis problemas relacionados ao hardware.

// FLUXO DO SISTEMA

Como a auditoria acontece?

O fluxo foi pensado para conectar o computador central aos computadores da rede de forma organizada.

01 / DISCOVERY

Descoberta

O computador central procura dispositivos disponíveis na rede local.

02 / REQUEST

Solicitação

O sistema solicita autorização para disponibilizar as informações do computador.

03 / DATA

Coleta

O computador autorizado envia informações relacionadas ao seu hardware.

04 / ANALYSIS

Auditoria

Os dados podem ser apresentados para facilitar a análise e a manutenção.

// PRÓXIMOS PASSOS

Futuras melhorias.

O Net Guard ainda vai evoluir. A ideia é deixar tudo mais simples para quem usa no dia a dia.

1×

Autorização uma única vez

Hoje o computador precisa liberar o acesso às suas informações. No futuro, o aluno autoriza apenas uma vez e o computador fica reconhecido, sem precisar pedir permissão toda hora.

↻

Nova autorização só se trocar peças

Se alguém trocar uma peça do computador (memória, HD, processador...), o sistema percebe a mudança e pede uma nova autorização, só para atualizar as informações.

✓

Informações sempre em dia

Como o sistema percebe quando algo muda, os dados de cada computador ficam atualizados sem ninguém precisar conferir tudo na mão.

☰

Histórico das trocas

Guardar um registro de quando uma peça foi trocada, para o responsável saber a história de cada máquina de forma simples.
